================================================================================
FEATURE OVERVIEW
================================================================================

WHAT IT DOES:
  - Adds checkbox to Add Team and Edit Team forms
  - When checked: Hides Adviser/Professor role option
  - Only shows: Leader and Member roles
  - Auto-converts adviser assignments to leader if needed
  - Stores value in database (0 or 1)

WHERE IT APPEARS:
  - Add Team modal (/dashboard → Teams Tab → Add Team)
  - Edit Team modal (/dashboard → Teams Tab → Edit)

HOW IT WORKS:
  1. User checks "Title Proposal" checkbox
  2. JavaScript handler hides adviser option
  3. Form submits with title_proposal=1
  4. Backend validates and saves to database
  5. On edit, checkbox shows current state

BACKWARD COMPATIBLE:
  - Teams created before feature default to title_proposal=0
  - Normal operation unchanged
  - Can be toggled anytime
  - Existing adviser roles work normally if unchecked
