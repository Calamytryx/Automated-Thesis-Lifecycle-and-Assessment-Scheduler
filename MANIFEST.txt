API ENDPOINTS (6 TOTAL)
================================================================================

All in: /api/admin_overrides.php

1. GET ?action=get_team_defense_info&team_id=X
   Purpose: Fetch team's current defense type and override status
   Auth: Admin only

2. POST ?action=set_defense_type_override
   Params: team_id, override_type, reason, expires_at (optional)
   Purpose: Set admin override for team
   Auth: Admin only

3. POST ?action=remove_defense_type_override
   Params: team_id
   Purpose: Remove override
   Auth: Admin only

4. POST ?action=lock_panelists
   Params: team_id, defense_type, panelist_ids[]
   Purpose: Lock panelists for stage
   Auth: Admin only

5. POST ?action=unlock_panelists
   Params: team_id, defense_type
   Purpose: Unlock panelists
   Auth: Admin only

6. GET ?action=get_team_panelists&team_id=X
   Purpose: Fetch panelists for all stages
   Auth: Admin only
