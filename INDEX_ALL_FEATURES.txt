FEATURE 3: PROGRAM/COLLEGE FILTERING
================================================================================

WHAT IT DOES:
  • All program dropdowns now filter by user role
  • Superadmin: Sees ALL programs from ALL colleges
  • Admin: Sees only their college's programs
  • Faculty: Sees only their assigned section program

WHERE APPLIED:
  • Team Add/Edit forms
  • User Add/Edit forms
  • All program selectors
  • Any form with program dropdown

HOW IT WORKS:
  User requests programs
    ↓
  System checks user role
    ├─ ID=0 (Superadmin) → All programs
    ├─ usertype=0 (Admin) → College programs only
    └─ Faculty → Assigned program only
    ↓
  Returns filtered list

IMPLEMENTATION:
  • File: get_programs_grouped.php
  • Changes: ~40 lines
  • Backward compatible: 100%
