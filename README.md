## Features

### Thesis Topic Decision Tool
- Utilizes an API or internal database to suggest relevant research topics
- Ensures quality thesis projects based on current academic trends

### Research Title Acceptance Tool
- Assesses the uniqueness of titles using open-access repositories
- Analyzes titles with the Gemini Pro LLM model

### Scheduling System
- Aligns defense schedules for students and panelists based on availability
- Implements efficient scheduling algorithms

### Content Management System
- Allows modular modification of:
  - Rubrics
  - Team lists
  - Title lists
  - Panelist assignments
- Customizable system appearance

### Requirement Checker Tool
- Helps students and advisers track completion of necessary documents before defense

### Pass Recommendation System
- Utilizes Gemini Pro LLM to process:
  - Panelists' scores
  - Comments
  - Paper sentiment
- Generates automated, suggestive feedback
- Improves consistency and reduces errors in evaluation
