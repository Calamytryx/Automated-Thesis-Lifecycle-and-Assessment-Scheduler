## 🎓 FEATURE OVERVIEW

### What It Does
Users can mark thesis teams as "Title Proposal" which automatically:
- Hides the Adviser/Professor role option
- Shows only Leader and Member roles
- Auto-converts any adviser assignments to leader
- Saves state in database (0=normal, 1=title_proposal)

### Where It Appears
- Add Team form ✅
- Edit Team form ✅
- Works in both places seamlessly

### User Experience
1. Open team form
2. See checkbox "Title Proposal"
3. Check it if desired
4. Role options update automatically
5. Save team
6. Value persists in database
